# CaspianCoast

Корпоративный сайт строительно-девелоперской компании. React + Vite + TypeScript, мультиязычный интерфейс (RU / KZ / EN).

## Требования

- Node.js 18+
- npm

## Установка

```bash
npm install
```

## Команды

```bash
npm run dev      # запуск dev-сервера
npm run build    # production-сборка
npm run preview  # предпросмотр сборки
npm run lint     # проверка линтером
```
